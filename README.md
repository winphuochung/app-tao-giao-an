# EdTech GDPT 2018 - Hệ Thống Soạn Kế Hoạch Bài Dạy & Slide Chuyên Nghiệp

Hệ thống web app thông minh hỗ trợ giáo viên soạn thảo Kế hoạch bài dạy (Giáo án) và Slide bài giảng trình chiếu chuẩn Chương trình Giáo dục phổ thông 2018 (GDPT 2018).

## ✨ Điểm Nổi Bật

- **Chuẩn Thể thức Công văn Bộ GD&ĐT**:
  - Cấp Tiểu học: Chuẩn **Công văn 2345/BGDĐT-GDTH** (Bảng 2 cột: Hoạt động của giáo viên & Hoạt động của học sinh).
  - Cấp THCS: Chuẩn **Công văn 5512/BGDĐT-GDTrH** (Bảng 2 cột với đủ 4 bước sư phạm: *Chuyển giao nhiệm vụ $\rightarrow$ Thực hiện nhiệm vụ $\rightarrow$ Báo cáo thảo luận $\rightarrow$ Kết luận nhận định*).
- **Phân tách Đề mục SGK bám sát thực tế**:
  - Mỗi đề mục trong Sách giáo khoa là một hoạt động hình thành kiến thức độc lập (Hoạt động 2.1, 2.2, 2.3...), có đầy đủ a) Mục tiêu, b) Nội dung, c) Sản phẩm, d) Tổ chức thực hiện.
- **Tích hợp Sách Giáo Khoa Điện Tử NXB Giáo Dục Việt Nam**:
  - Liên kết trực tiếp cổng SGK điện tử: `https://taphuan.nxbgd.vn/tap-huan?grade=...`.
  - Hỗ trợ đầy đủ các khối lớp từ Lớp 1 đến Lớp 9 của tất cả các môn học (Toán, KHTN, Khoa học, Ngữ văn, Lịch sử & Địa lí, Công nghệ, GDCD...).
- **Phương pháp dạy học tích cực & Đổi mới sáng tạo**:
  - Hoạt động nhóm 4 vai trò (Nhóm trưởng, Thư ký, Kỹ thuật viên, Báo cáo viên) với quy tắc 4 màu mực chống thụ động.
  - Sơ đồ tư duy 16:9 phong cách 3D Pixar chốt kiến thức cốt lõi.
  - Tích hợp chuẩn chỉ số Năng lực số theo **Công văn 3456/BGDĐT-GDPT**.
  - Lồng ghép Giáo dục Quốc phòng & An ninh (Thông tư 08/2024/TT-BGDĐT), An toàn giao thông, STEM, Kỹ năng sống.
- **Xuất file đa định dạng chuẩn in ấn**:
  - **Tải Giáo Án (.DOCX)**: File Word format chuẩn thể thức văn bản hành chính Việt Nam (Times New Roman, căn lề, bảng viền đen).
  - **Tải Slide Bài Giảng (.PPTX)**: File PowerPoint 16:9 chuyên nghiệp với hiệu ứng và bố cục Bento Grid, Split View.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Ứng Dụng

### Yêu cầu môi trường
- Node.js (phiên bản 18+ trở lên)
- Trình duyệt Chrome / Edge / Firefox

### Cài đặt
```bash
# Cài đặt các thư viện cần thiết
npm install
```

### Chạy ứng dụng ở môi trường phát triển (Development)
```bash
npm run dev
```
Truy cập tại: `http://localhost:5173/`

### Build phiên bản triển khai (Production)
```bash
npm run build
```
